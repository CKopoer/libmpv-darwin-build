# Corresponding source and third-party notices

Rebuild instructions and pinned upstream source commits are in the accompanying workflow. The dependency manifest records the exact static archives and their SHA-256 checksums. Each release URL identifies the component build recipe, source version, patches and configuration. The workflow builds LGPL libmpv without the GPL option and embeds the selected archives into a replaceable dynamic framework.
